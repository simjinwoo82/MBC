🎨 CSS 이름표 붙이기: Class와 ID

웹페이지를 예쁘게 꾸밀 때, 어떤 태그에 색칠할지 "이름표"를 붙여줘야 해요.
이름표에는 두 가지 종류가 있답니다!

👯‍♀️ Class (클래스) - "같은 반 친구들"

🧸 쉬운 비유: 학교의 '반(Class)'을 생각해 보세요!
"3학년 1반 친구들, 모두 일어나세요!" 하면 여러 명이 동시에 일어나죠?

클래스는 여러 명에게 똑같은 이름표를 붙여줄 때 써요.

예를 들어, "중요한 글자"라는 뜻으로 class="important"라고 여러 곳에 붙일 수 있어요.

<!-- HTML에서 이름표 붙이기 -->
<p class="red-text">나는 빨간색!</p>
<p class="red-text">나도 빨간색!</p>

/* CSS에서 부르기 (점 . 을 찍어요!) */
.red-text { color: red; }

👑 ID (아이디) - "오직 한 명뿐인 반장"

🧸 쉬운 비유: 여러분의 '주민등록번호'나 '학번'을 생각해 보세요!
"3학년 1반 15번 김철수 나와라!" 하면 딱 한 명만 나오겠죠?

아이디는 웹페이지에서 딱 하나만 있어야 하는 특별한 이름표예요.

예를 들어, 웹사이트 맨 위에 있는 "로고"는 하나뿐이니까 id="logo"라고 붙여요.

<!-- HTML에서 이름표 붙이기 -->
<h1 id="main-title">진짜 중요한 딱 하나의 제목</h1>

/* CSS에서 부르기 (우물 정 # 을 찍어요!) */
#main-title { font-size: 50px; }

⚖️ 한눈에 비교하기

👯‍♀️ Class (클래스) 👑 ID (아이디)
몇 명에게? 여러 명에게 똑같이 붙일 수 있어요 ⭕ 딱 한 명에게만 붙일 수 있어요 ☝️
CSS에서 부를 때 점 ( . ) 을 찍고 불러요
.my-class		 우물 정 ( # ) 을 찍고 불러요
#my-id
누가 더 힘이 셀까? 힘이 약해요 💪 힘이 엄청 세요! 💪💪💪
(둘이 싸우면 ID가 이겨요)
🌟 기억하세요!
여러 개를 예쁘게 꾸밀 땐 "클래스( . )"
딱 하나만 특별하게 꾸밀 땐 "아이디( # )"
