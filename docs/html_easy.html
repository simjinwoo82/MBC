🏠 HTML은 웹페이지의 뼈대야!

📖 HTML이 뭐예요?

HTML은 웹페이지를 만드는 언어예요.

쉽게 말하면, 웹사이트의 설계도라고 생각하면 돼요!

우리가 보는 모든 웹사이트(유튜브, 네이버, 게임 사이트 등)는 HTML로 만들어졌어요.

🏠 집에 비유해서 이해필게요

HTML 문서는 집과 똑같아요! 집은 여러 공간으로 나뉘죠?

🔑 1. <!DOCTYPE html> - "이 집은 HTML5 집이에요!"

집 문 앞에 붙은 주소판 같은 거예요.

브라우저(크롬, 사파리)에게 "이 문서는 HTML5로 만들었어!" 라고 알려주는 거예요.

💡 꿀팁: 이 줄은 항상 맨 위에 써야 해요. 안 그러면 브라우저가 헷갈려요!
⬇️

🧱 2. <html> - "집 전체"

모든 것을 감싸는 집 전체예요.

모든 내용은 이 안에 들어가요. 집 안에 방이 있는 것처럼!

⬇️ 이 안에 두 개의 방이 있어요

🧠 3. <head> - "보이지 않는 창고"

이 방은 화면에 안 보여요!

하지만 중요한 것들이 여기 있어요:

  • 📛 문서 이름 (브라우저 탭에 보이는 제목)
  • 🔤 한글을 제대로 보여주는 설정
  • 🎨 예쁘게 꾸미는 옷(CSS) 파일 연결

마치 집 안의 창고나 서랍 같은 곳이에요. 안 보여도 꼭 필요해요!

⬇️

🖥️ 4. <body> - "손님을 맞이하는 거실"

이 방은 화면에 다 보여요!

글자, 사진, 버튼, 동영상 등 우리가 보는 모든 것이 여기 있어요.

마치 손님이 오면 보여주는 거실이에요!

🔍 실제 코드로 보기

이제 집 구조를 실제 HTML 코드로 볼까요?

<!DOCTYPE html>                        <-- "이건 HTML5 집이에요!" (주소판)
<html>                                   <-- "집 전체 시작!"
    <head>                               <-- "창고 시작" (화면에 안 보임)
        <meta charset="UTF-8">         <-- "한글 제대로 보여줘!"
        <title>내 첫 웹페이지</title>    <-- "브라우저 탭 제목"
    </head>                            <-- "창고 끝"
    <body>                             <-- "거실 시작!" (화면에 보임)
        <h1>안녕하세요!</h1>          <-- 큰 제목
        <p>나의 첫 웹페이지예요.</p>  <-- 문단
    </body>                            <-- "거실 끝"
</html>                                <-- "집 전체 끝!"

📋 각 부분 딱 3줄 요약

<!DOCTYPE html> 이 문서가 HTML5라고 알려주는 주소판이에요.
항상 맨 첫 줄에 써요.
<html> 모든 내용을 감싸는 집 전체예요.
시작 태그와 끝 태그가 있어요.
<head> 화면에 안 보이는 창고예요.
이름, 설정, 옷(CSS)을 여기 넣어요.
<body> 화면에 보이는 거실이에요.
글자, 사진, 버튼 등을 여기 넣어요.

🎯 중요한 규칙!

  1. 여는 태그가 있으면 닫는 태그가 있어야 해요
        <html> ... </html>
        <body> ... </body>
  2. 태그는 <> 안에 써요 (엇갈림 괄호)
  3. 닫는 태그에는 / 슬래시가 들어가요
  4. <head>는 보이지 않아요, <body>는 보여요

🧩 비유 정리

HTML 문서 = 🏠 집

<!DOCTYPE> = 🔑 집 앞 주소판
<html> = 🧱 집 전체 벽
<head> = 📦 보이지 않는 창고
<body> = 🛋️ 손님 보는 거실

🌟 기억하세요! 모든 웹사이트는 이 4가지로 시작해요. 이 구조만 알면 반은 먹고 들어가는 거예요!
