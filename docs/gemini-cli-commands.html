Gemini CLI 슬래시 명령어 가이드

Gemini CLI에서 사용할 수 있는 주요 슬래시 명령어 목록입니다. 명령어는 채팅 입력창에 /를 입력하여 실행할 수 있습니다.

일반 및 도움말 (General & Help)

명령어설명
/help (또는 /?)도움말 정보를 표시합니다. 사용 가능한 명령어와 사용법을 확인하세요.
/about버전 정보를 표시합니다. 문제 보고 시 유용합니다.
/docs브라우저에서 Gemini CLI 공식 문서를 엽니다.
/bug <제목>GitHub에 Gemini CLI 관련 이슈를 생성합니다.
/privacy개인정보 보호 고지 및 데이터 수집 동의 옵션을 표시합니다.
/quit (또는 /exit)CLI를 종료합니다. --delete 옵션으로 기록을 삭제할 수 있습니다.

세션 및 컨텍스트 관리 (Session & Context)

명령어설명
/resume (alias: /chat)이전 세션을 탐색하고 다시 시작하거나 체크포인트를 관리합니다.
/rewind대화 기록을 되돌려 상호작용을 검토하거나 변경 사항을 취소합니다.
/restore [tool_id]특정 도구 실행 전의 상태로 프로젝트 파일을 복원합니다.
/clear터미널 화면과 표시된 세션 기록을 지웁니다.
/compress채팅 컨텍스트를 요약으로 교체하여 토큰을 절약합니다.
/memoryGEMINI.md 파일의 지침 컨텍스트를 관리합니다.
/stats세션, 모델 또는 도구 사용 통계를 보여줍니다.

설정 및 사용자 정의 (Settings)

명령어설명
/settings대화형 설정 편집기를 엽니다.
/theme시각적 테마를 변경하는 대화창을 엽니다.
/model모델 구성을 관리합니다 (예: /model set <name>).
/auth인증 방식을 변경하는 대화창을 엽니다.
/editor파일 작업에 사용할 기본 에디터를 선택합니다.
/vimVim 스타일의 내비게이션 및 편집 모드를 토글합니다.

워크스페이스 및 도구 (Workspace & Tools)

명령어설명
/dir (또는 /directory)워크스페이스 디렉토리를 관리합니다.
/tools사용 가능한 도구 목록을 보여줍니다.
/mcpModel Context Protocol (MCP) 서버를 관리합니다.
/skills에이전트 스킬(전문 지식)을 관리합니다.
/agents로컬 및 원격 서브 에이전트를 관리합니다.
/plan계획 모드(Plan Mode)로 전환하거나 현재 계획을 확인합니다.

기타 유용한 기능 (Advanced)

명령어설명
/init현재 프로젝트에 최적화된 GEMINI.md 파일을 생성합니다.
/copy마지막 CLI 출력을 클립보드에 복사합니다.
/upgrade사용량 제한 상향을 위한 업그레이드 페이지를 엽니다.
/shells백그라운드에서 실행 중인 셸 프로세스 뷰를 토글합니다.
