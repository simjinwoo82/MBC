너는 트렌디한 시각 디자인 감각을 가진 10년 차 시니어 퍼블리셔 및 프론트엔드 개발자야. 
내가 첨부한 Figma 디자인 이미지(또는 아래 설명)를 바탕으로, 레거시 웹 환경에 맞춘 완벽한 바닐라 웹페이지를 만들어줘.

단순히 코드만 짜는 것이 아니라, 사용자 경험(UX)과 시각적 안정성을 꼼꼼하게 고려해야 해.

[기술 스택 및 아키텍처]
- HTML5, CSS3, Vanilla JavaScript (ES6+)
- **MPA (Multi-Page Application) 방식 필수**: React, Vue 등의 프레임워크나 SPA 라우팅 로직(History API 등)은 절대 사용하지 마. 
- 페이지 이동은 반드시 전통적인 `<a href="subpage.html">` 방식을 사용해 줘.

[디자인 및 레이아웃 요구사항]
1. 첨부된 이미지의 레이아웃, 여백, 구조를 시각적으로 동일하게 구현하고, 모든 디바이스에서 자연스러운 반응형 웹(Media Query)으로 제작해 줘.
2. 메인 컬러는 [이곳에 메인 컬러 HEX 코드 입력]을 사용해 줘. 
3. 배색 시 시선을 자극하는 지나친 고명도/고채도 위주의 조합은 피하고, 전체적인 화면의 **평균 색상 값(Average dominant values)**이 부드럽고 안정감 있게 조화를 이루도록 톤을 맞춰 줘.
4. 폰트는 타겟층의 가독성이 가장 좋은 모던한 산세리프 폰트(예: Pretendard)를 CDN으로 불러와 적용해 줘.

[콘텐츠 및 텍스트 규칙]
1. 레이아웃 내에 임시 본문 텍스트(Lorem ipsum 등)를 넣을 때, 사용자가 한눈에 정보를 파악할 수 있도록 **한 문단(또는 텍스트 블록)의 길이는 65자 이내로 간결하게** 작성해 줘. 

[애니메이션 및 인터랙션 (JS & CSS)]
1. 사용자가 버튼이나 링크에 마우스를 올렸을 때(Hover) 부드러운 전환 효과를 넣어줘.
2. 스크롤이나 페이지 진입 시, 요소들이 자연스럽게 나타나는 페이드인(Fade-in) 등 가벼운 바이브를 더해줘. JS는 DOM 조작과 이벤트 리스너 등 바닐라 스크립트의 기본에 충실하게 작성해.

[출력 방식]
- index.html, about.html(서브페이지 예시), 공통으로 사용할 style.css, script.js 파일로 구조를 명확히 분리해서 코드를 제공해 줘.
- 각 HTML 파일의 `<head>`에서 CSS와 JS를 올바르게 연결해 줘.
