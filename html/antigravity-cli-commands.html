세션 관리

대화 세션의 시작, 종료, 전환, 분기 등을 관리하는 명령어입니다.

/exit · /quit 현재 Antigravity CLI 세션을 종료합니다.
/resume · /switch · /conversation 이전 대화 스레드를 ID 또는 이름으로 검색해 재개합니다.
/fork · /branch 현재 대화를 히스토리를 유지한 채 새 스레드로 분기합니다.
/rename 활성 대화 스레드의 이름을 변경합니다.
/rewind · /undo 대화 히스토리를 이전 체크포인트로 되돌립니다.
/clear · /new 터미널 화면과 스크롤백 버퍼를 초기화합니다.
/logout 현재 Google 계정 세션에서 로그아웃합니다.
📁

워크스페이스 & 코드

프로젝트 디렉터리, 파일, 코드 변경 사항을 관리하는 명령어입니다.

/add-dir 활성 프로젝트 워크스페이스에 새 디렉터리 경로를 추가합니다.
/diff 에이전트가 수행한 현재 코드베이스 변경사항(diff)을 표시합니다.
/open 지정된 파일을 로컬 편집기(VS Code, Vim 등)에서 엽니다.
/context 에이전트의 현재 컨텍스트에 포함된 모든 파일과 심볼을 나열합니다.
🤖

에이전트 & 도구

AI 에이전트, 모델, MCP 서버, 스킬, 권한 등을 제어하는 명령어입니다.

/model 세션에서 사용할 활성 Gemini 모델을 변경합니다.
/agents 모든 활성 서브에이전트와 커스텀 에이전트를 나열합니다.
/skills 모든 활성 에이전트 스킬을 나열합니다.
/mcp 활성 MCP 서버와 노출된 도구(tool)들을 나열합니다.
/hooks 등록된 모든 라이프사이클 훅(hooks)을 나열합니다.
/permissions 도구 실행 권한(허용/거부 목록)을 관리합니다.
/tasks 활성 작업 목록과 진행 상황을 표시합니다.
/btw 에이전트 실행 없이 간단한 사이드 질문을 합니다.
🎨

화면 & UI

터미널 인터페이스의 표시, 복사, 뷰어 등 시각적 요소를 제어하는 명령어입니다.

/artifact TUI 아티팩트 뷰어를 엽니다.
/copy 마지막 에이전트 응답을 시스템 클립보드에 복사합니다.
/config · /settings TUI 설정 패널을 열어 환경을 커스터마이즈합니다.
/fast 타이핑 딜레이와 사고 시각화의 빠른 모드를 토글합니다.
/statusline 터미널 하단 상태 줄을 토글합니다.
/title 터미널 타이틀을 토글하거나 설정합니다.
/planning 인터랙티브 그래픽 플래닝 및 태스크 리스트 에디터를 엽니다.
/usage · /quota 토큰 사용량과 세션 비용 통계를 표시합니다.
/help 도움말 메뉴와 명령어, 단축키를 표시합니다.
/changelog 제품 변경 로그와 릴리즈 노트를 표시합니다.
/keybindings 모든 활성 CLI 키보드 단축키를 설정합니다.
/feedback 제품 피드백 및 버그 리포트 양식을 엽니다.
/credits 서드파티 소프트웨어 라이선스 및 저작자 표시를 보여줍니다.
⌨️

키보드 단축키

터미널에서 빠르게 사용할 수 있는 단축키입니다.

ESC 활성 메뉴(스킬, 설정 등)를 닫습니다
Ctrl+D Ctrl+D CLI를 종료합니다 (/exit와 동일)
↑ / ↓ 명령어 히스토리를 탐색합니다
Enter 최초 실행 시 브라우저 OAuth 인증 시작
⚙️

설정 (settings.json)

~/.gemini/antigravity-cli/settings.json 파일에서 설정 가능한 모든 키입니다.

키 타입 설명 기본값
allowNonWorkspaceAccess bool 워크스페이스 루트 외부의 파일 읽기/쓰기를 허용합니다. false
altScreenMode string 대체 화면 버퍼 사용을 제어합니다. (default, always, never) "default"
artifactReviewPolicy string 아티팩트 리뷰 요청 시점을 제어합니다. (always-proceed, agent-decides, asks-for-review) "asks-for-review"
colorScheme string CLI 색상 스킴입니다. (terminal, dark, light) "terminal"
editor string 파일을 열 때 사용할 편집기 명령어입니다. (예: vim, nano, auto) "auto"
enableTelemetry bool 익명 사용량 및 크래시 리포팅을 토글합니다. true
enableTerminalSandbox bool 터미널 명령을 제한된 샌드박스 환경에서 실행합니다. false
gcp object 클라우드 기반 도구를 위한 GCP 프로젝트 및 위치 설정입니다. nil
historySize int 디스크에 저장할 최대 히스토리 항목 수입니다. (-1은 무제한) 2000
model string 메인 에이전트가 사용하는 활성 모델 식별자입니다. "gemini-3.5-flash"
notifications bool 작업 완료 시 시스템 알림을 활성화합니다. false
permissions object 파일, 명령어, URL에 대한 전역 허용/거부/확인 규칙입니다. nil
runningLightSpeed string 사고 시각화를 위한 인위적 타이핑 딜레이입니다. (off, fast, medium, slow) "medium"
showFeedbackSurvey bool 주기적 제품 피드백 설문을 표시합니다. true
showTips bool CLI에 유용한 팁과 단축키를 표시합니다. true
statusLine object TUI 상태 줄 설정입니다. nil
title object TUI 타이틀 설정입니다. nil
toolPermission string 도구 확인 모드입니다. (always-proceed, request-review, strict, proceed-in-sandbox) "request-review"
trustedWorkspaces array 사용자가 실행을 허용하는 신뢰 디렉터리 경로 목록입니다. []
useG1Credits bool Google One AI 프리미엄 쿼터 사용을 토글합니다. false
verbosity string 에이전트 트레이스 렌더링의 상세도입니다. (high, low) "high"
