Gemini CLI 실행 가이드

윈도우 환경에서 어느 폴더에서나 Gemini CLI를 간편하게 실행하는 방법

방법 1: '보내기(Send To)' 메뉴 등록 (가장 추천)

어느 폴더에서든 마우스 오른쪽 클릭만으로 Gemini CLI를 실행할 수 있습니다.

  1. 생성된 gemini-launcher.bat 파일을 마우스 오른쪽 클릭하여 [바로가기 만들기]를 선택합니다.
  2. 키보드의 Win + R 키를 누릅니다.
  3. 입력창에 shell:sendto를 입력하고 엔터를 누릅니다.
  4. 열린 폴더 안에 아까 만든 '바로가기 파일'을 복사해서 넣습니다.
  5. 사용법: 이제 작업하고 싶은 폴더를 마우스 오른쪽 클릭 -> 보내기(N) -> gemini-launcher를 클릭하면 끝!

방법 2: 환경 변수(Path)에 등록하기

터미널(CMD, PowerShell) 어디서든 명령어로 실행하고 싶을 때 사용합니다.

  1. gemini-launcher.bat 파일을 시스템 경로(예: C:\Windows)에 복사합니다.
  2. 또는 파일이 있는 폴더 경로를 [시스템 환경 변수 편집] -> [Path]에 추가합니다.
  3. 사용법: 터미널을 열고 아무 경로에서나 gemini-launcher라고 입력합니다.

방법 3: 직접 복사하여 실행

  1. gemini-launcher.bat 파일을 작업하려는 폴더로 복사합니다.
  2. 파일을 더블 클릭하면 즉시 해당 위치에서 Gemini CLI가 시작됩니다.
💡 팁: 배포된 배치 파일은 실행 시 자동으로 Gemini CLI 설치 여부를 확인하며, 실행 후 오류가 발생할 경우 창이 바로 닫히지 않고 오류 메시지를 보여줍니다.
